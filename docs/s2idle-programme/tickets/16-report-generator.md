# 16: Report generator

**What to build:** a generator that takes the measurement job records and produces a sophisticated HTML report with explanatory charts: draw per level, per-block attribution, reliability cycles, before/after per patch, and a dead-ends section. Tested by feeding it a fixed set of records.
