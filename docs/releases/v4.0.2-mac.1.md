# Omarchy MX Mac 4.0.2-mac.1

## Highlights

- Integrates upstream Omarchy 4.0.2 while retaining the Apple Silicon hardware
  detector, signed package channel, safe update path, and boot protections.
- Includes upstream security hardening for SSH password logins, the blanket
  desktop input-group grant, browser policy directories and web app
  definitions, printer discovery and print-filter privileges, Plymouth theme
  publication, Windows VM mount boundaries, and privileged files left behind
  by retired installers.
- Adopts the upstream Quattro upgrade verification that fails the upgrade when
  migrations do not complete, while keeping the Apple Silicon step ordering
  and package guards.
- Reviews all ten new upstream migrations for Apple Silicon. All ten run: the
  signed-repository and rc-channel repairs are verified no-ops on the already
  signature-required Apple Silicon package setup, and the CUPS privilege
  separation was confirmed against aarch64 package availability.
- Aligns the Apple Silicon base package manifest with the upstream CUPS
  posture: `cups-browsed` and `cups-pdf` are removed and `cups-pk-helper` is
  added after confirming it resolves in the Asahi channels.

## Validation

- The complete CLI and shell source test suites passed in an isolated aarch64
  Linux container against the merged tree.
- Apple Silicon migration coverage confirms every bundled migration has an
  explicit disposition and continues to fail closed for unknown migrations.
- `cups-pk-helper` was confirmed available for aarch64 in the Arch Linux ARM
  extra repository before entering the Apple Silicon manifest.
- Generic ARM64 QEMU/HVF VM acceptance on the M4 builder (2026-09-01): a fresh
  encrypted install from the accepted 4.0.1 acceptance ISO, followed by the
  real upgrade path — all eleven pending migrations ran to completion in the
  guest, including the CUPS privilege separation, input-group removal, and
  live sshd key-only hardening — then a reboot of the upgraded system through
  graphical Plymouth unlock, and a full acceptance-suite pass (111 checks)
  against the 4.0.2 tree. Evidence is retained in the
  `omarchy-v4.0.2-arm64-acceptance-20260901` work area on the builder.

## Known Limitations

- No 4.0.2 package candidate, rebuilt ISO, or channel sequence exists yet;
  those follow the established qualification pipeline before any channel is
  advanced.
- The 4.0.2 package build must ship the hardened CUPS `cups-files.conf`
  (SystemGroup without `wheel`, per upstream's omarchy-settings packaging);
  migrations intentionally do not rewrite that package-owned file, and the VM
  run verified the acceptance check passes exactly when the package content is
  present.
- Generic VM validation cannot cover Apple GPU, Wi-Fi, audio, suspend, input
  hardware, or other physical hardware behavior.
- Physical Apple-hardware acceptance is not claimed by this release.
- The Apple package repositories do not currently expose `mise-bin`; the
  validated package bundle also intentionally retains `quickshell-git`.
