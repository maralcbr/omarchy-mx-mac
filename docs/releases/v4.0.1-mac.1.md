# Omarchy MX Mac 4.0.1-mac.1

## Highlights

- Integrates upstream Omarchy 4.0.1 while retaining the Apple Silicon hardware
  detector, signed package channel, safe update path, and boot protections.
- Includes upstream security hardening for untrusted Git URLs, installed theme
  contents, FIDO2 credential files, desktop notifications, DNS changes, and
  Windows VM configuration and mount sources.
- Adds the upstream input-device state migration and monitor recovery fixes,
  along with Docker posture, networking, shell, and application improvements.
- Reviews all eight new upstream migrations for Apple Silicon. Six
  architecture-neutral or platform-safe repairs run normally; the `mise-bin`
  and `quickshell` package swaps remain held because the
  validated Apple Silicon bundle still provides `mise` and `quickshell-git`.

## Validation

- All 218 source test files passed in an isolated checkout with Node 24,
  including the complete CLI and shell suites.
- Apple Silicon migration coverage confirms every bundled migration has an
  explicit disposition and continues to fail closed for unknown migrations.
- Package publication, disposable Asahi VM validation, and physical M1 Pro
  update validation remain release gates and will run only after the separate
  ISO work reaches its agreed safe checkpoint.

## Known Limitations

- This source candidate is not a published stable release until its exact
  commit is packaged, installed and updated in disposable Asahi VMs, and then
  validated on the M1 Pro before the immutable tag is created.
- Generic VM validation cannot cover Apple GPU, Wi-Fi, audio, suspend, input
  hardware, or other physical hardware behavior.
- The Apple package repositories do not currently expose `mise-bin`; the
  validated package bundle also intentionally retains `quickshell-git`.
