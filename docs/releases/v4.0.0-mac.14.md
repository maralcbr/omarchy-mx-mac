# Omarchy MX Mac 4.0.0-mac.14

## Highlights

- Adds version-controlled release notes and a maintained Apple Silicon
  changelog.
- Introduces parallel native-ARM package preparation with signed immutable
  package reuse and GitHub Actions builder caching.
- Keeps signing secrets and release write access confined to the final
  protected job after exact six-package fan-in verification.

## Validation

- The source suite and focused Apple Silicon release gates passed.
- The package workflow's safe verification mode completed a cold six-package
  build before publication.
- Signed package sequence 18 passed fresh public download, checksum, signature,
  architecture, source-binding, and channel monotonicity checks.

## Known Limitations

- The first accelerated release rebuilds every package because prior releases
  predate the package build-key contract; later unchanged releases can reuse
  four source-independent packages.
- Zed remains unavailable in the current aarch64 repositories and is hidden by
  the install menu availability guard.
- Generic VM validation cannot cover Apple GPU, Wi-Fi, audio, suspend, or other
  physical hardware behavior.
