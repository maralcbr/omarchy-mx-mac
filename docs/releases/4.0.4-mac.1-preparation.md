# Omarchy MX Mac 4.0.4 preparation

Status: published 2026-09-23 as [4.0.4-mac.1](v4.0.4-mac.1.md). This record is
the pre-release preparation and is kept as written below.

The runtime integrates upstream `omacom/omarchy` tag `v4.0.4`, commit
`c668141e9c42b13c80c9ca4ea108e11708c5e8a5`, on the Mac fork based at
`108dff6e`. Product version: `4.0.4-mac.1`.

## Integration decisions

Upstream 4.0.4 only changes the x86 kernel: installs move to `linux-omarchy`
(except T2 Macs), Limine prefers it, DKMS installers stop naming
`linux-headers`, and the Dell XPS Panther Lake kernel swap is retired. Apple
Silicon keeps `linux-asahi` or `linux-aurora` with GRUB; nothing here may
change its kernel, boot loader or boot configuration.

- Settle both new migrations as skipped in the Asahi migration policy.
  `1789325478` installs `linux-omarchy` and rewrites the Limine boot order; it
  also exits on anything but x86_64. `1789444024` installs `linux-omarchy` or
  `linux-t2` headers; it also exits early on Apple Silicon hardware.
- The Limine `BOOT_ORDER` change never reaches Apple Silicon: the aarch64
  settings package drops `/etc/limine-entry-tool.d`.
- `install/omarchy-other.packages` now names `linux-omarchy`; the Asahi package
  lists are unchanged and reject both x86 kernel names. The package resolver
  counts them as upstream-only, like the retired `linux-ptl-headers`.
- Removing `intel/ptl-kernel.sh` and the NVIDIA header step touches only
  hardware Apple Silicon never matches. The fork's Apple hardware steps and the
  `pacman.sh` step in `install/hardware/all.sh` remain.
- Keep the fork's Xbox controller recipe, which installs the headers for the
  Apple kernel in use. Take upstream's Broadcom BCM4360/4331 line; that
  hardware only exists in Intel Macs.
- The acceptance header check expects the Apple kernel on Apple Silicon and
  the stock Arch Linux ARM kernel in generic ARM guests.

## Qualification and publication boundary

This is preparation, not a published release. No package candidate, payload or
channel has been built or moved for it. Upgrade an existing 4.0.3 Mac first and
confirm the kernel, GRUB entries and `/boot` are unchanged before publication.
