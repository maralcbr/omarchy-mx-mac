# Omarchy MX Mac 4.0.0-mac.15

## Highlights

- Adds an immutable signed Apple Silicon package repository containing 21
  native or architecture-independent packages, including `omazed`.
- Audits every package manifest and optional transaction against signed Arch
  Linux ARM repositories and reviewed aarch64 build sources.
- Preserves UTF-8 locale generation when the installer inherits `LANG=C`.
- Enables PipeWire realtime scheduling through `rtkit` on Apple Silicon.
- Restores automatic GNOME Keyring unlock for password-based SDDM login.

## Validation

- All 199 source test files passed with the package and ISO integration
  checkouts enabled.
- Fresh-install and existing-system migration tests passed, including pinned-key
  verification, idempotency, Asahi repository preservation, and non-Apple
  hardware scoping.
- The immutable public package release contains 21 signed packages; pacman
  downloaded, verified, and installed `omazed 2.0.1-1` into an isolated aarch64
  root with required package signatures.

## Known Limitations

- Zed itself remains unavailable in the current aarch64 repositories, so its
  installer stays hidden even though the `omazed` integration is now published.
- Sunshine remains excluded because Arch Linux ARM does not provide `libmfx`.
- Generic VM validation cannot cover Apple GPU, Wi-Fi, audio, suspend, or other
  physical hardware behavior.
