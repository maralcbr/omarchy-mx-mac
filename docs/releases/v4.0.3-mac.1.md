# Omarchy MX Mac 4.0.3-mac.1

The Asahi RC fresh-install image is `os-v4.0.3-mac.1.20260913`. Select **RC**
in the signed macOS installer app. Existing Omarchy Macs can run
`omarchy update` to receive the same runtime and package snapshot through the
shared update feed.

## Changes

- Upstream Omarchy 4.0.3 security fixes, AI integrations, and Apple Silicon
  migration support, retaining the fork's ARM package and boot protections.
- ARM OpenClaw and Perplexity packages, with availability checks for unsupported
  applications.
- Greeter password masking and feedback, initial focus handling, and bounded
  focus rearming for multiple displays.
- Wait for Apple DRM devices before starting the greeter, and fix the
  initramfs static-device-node startup race.
- Include the RC installer default and release pruning lock preflight.
- Bind offline repository checkpoint identity to its normalization epoch.
- Confine native image-builder boot hooks to the image EFI partition using
  the vendor-supported builder marker; remove it before sealing.
- Use the pinned ALARM snapshot `20260910`, Linux Asahi platform inputs, and
  the signed installer engine `v0.9.0-omarchy.15`.
- Recover the pinned QEMU package from Debian's immutable snapshot archive,
  preserving its original version and SHA-256.

## Validation

The full package rebuild and final incremental runtime build passed their
clean-install and upgrade transaction gates. Package promotion preserved the
candidate bytes exactly and verified the immutable public release.

The exact final candidate passed native ARM64 VM installation on the M2 Max,
interruption recovery, reboot and installed-version checks, all 23 optional
application installs, and completed-installer rerun rejection without state
changes. See the [hash-bound acceptance record](asahi-packages-candidate-83973903-acceptance.txt).

Greeter password masking and focus were tested separately on the physical M2
Max with three displays. A fresh physical installation of the final Asahi OS
image has not been performed; this is an RC release.

The native builder isolation check passed against the M2 hardware device tree,
and the original host boot hash was verified after restoration. All 36
build-stage tests, five branding tests, and the ESP marker regression test
passed.

The final image passed qualification and release-publication checks. It has
not been independently rebuilt to identical bytes; the build report retains
that first-build reproducibility limitation. Payload SHA-256:
`befdc730e36a54b9cca0b63a2962bb5369f8d67bb94f33082f956fd2902ad13d`.

Source CI passed 277 of 278 shell test files. The unchanged failure is
`apple-platform-stack-test.sh`, whose older contract expects engine 7 while
this release uses engine 15. Whole-repository CI is not green.
