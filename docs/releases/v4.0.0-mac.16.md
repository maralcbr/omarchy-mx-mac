# Omarchy MX Mac 4.0.0-mac.16

## Highlights

- Early-loads `hid_apple` and `hid_magicmouse` from the Asahi initramfs to
  prevent the device rebinding race that can leave the internal trackpad
  unavailable for a session.
- Rebuilds the initramfs during fresh installation and applies a retryable,
  machine-idempotent migration to existing Apple Silicon installations.
- Detects the `apple-mtp-multi-touch` device name used by Apple MTP trackpads,
  restoring touchpad-guarded menu actions on affected models.
- Uses macOS-style natural scrolling and physical-click touchpad defaults while
  preserving user overrides.

## Validation

- All 201 source test files passed locally with Node 24, including fresh-install
  ordering, migration idempotency, failed-rebuild retry, device detection, and
  Hyprland configuration coverage.
- GitHub source tests, package source tests, all four manifest-resolution jobs,
  the optional-recipe audit, and both complete Asahi package transaction jobs
  passed on pull request 32.
- The current M1 Pro (`apple,j314s`) confirms `hid_apple`, `hid_magicmouse`, and
  `dockchannel-hid` are modular on the supported Asahi kernel. Its SPI trackpad
  remains detected by the existing `trackpad` pattern.

## Known Limitations

- The intermittent MTP trackpad race was reported on an M2 MacBook Air and
  cannot be reproduced deterministically on the M1 Pro validation machine.
- Applying the migration rebuilds the initramfs and requires a reboot before
  the early-loaded drivers take effect.
- Generic VM validation cannot cover Apple GPU, Wi-Fi, audio, suspend, input
  hardware, or other physical hardware behavior.
